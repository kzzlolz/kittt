# Gallery photos

Put your photos directly in this folder. The Gallery page on the website automatically finds and displays supported image files here.

Supported formats: PNG, JPG/JPEG, GIF, WEBP, and AVIF.

## Add a photo
1. Open the `gallery` folder on GitHub.
2. Choose **Add file → Upload files**.
3. Upload your pictures and commit the changes.
4. Refresh the website's Gallery tab after GitHub Pages updates.

The filename becomes the photo caption. Use friendly filenames like `sunset-at-the-beach.jpg` or `my-cat.png`.

No need to edit `webpage.html` when adding photos. Keep photos directly in this folder (not in nested folders).
